# IGCSE Grade Statistics Explorer (June 2026)

A Streamlit app that plots a bar chart of the grade statistics for each International GCSE subject, using Pearson's provisional June 2026 results.

## Run

```bash
pip install streamlit pandas matplotlib 
streamlit run app.py
```

Then open http://localhost:8501 and pick a subject.

## Source

Data: Pearson, *Grade Statistics (Provisional) - June 2026*, International GCSE (9-1).
https://qualifications.pearson.com/content/dam/pdf/Support/Grade-statistics/International-GCSE/grade-statistics-june-2026-provisional-international-gcse-9-1-specifications-international-only.pdf
